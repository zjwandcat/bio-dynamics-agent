# Project Philosophy

1. Scientific Correctness > Feature Count.
2. Reproducibility > Demo Smoothness.
3. Mechanism > LLM Guess.
4. Reaction Graph > Free-form Narrative.
5. Structured State > Hidden Context.
6. Canonical Evidence > Model Confidence.
7. Verified BioModels > Unverified BIOMD ID.
8. Validation > Prompt.
9. Benchmark Evidence > Screenshot.
10. Time Series > Final Scalar.
11. Provenance > Plausibility.
12. Explicit Fallback > Silent Fabrication.
13. Failure Honesty > Degraded Pass.
14. Negative Tests > Optimistic Claims.
15. Data Versioning > Memory.
16. Units Are Part of the Value.
17. Pathway Identity Is a Contract.
18. Templates Constrain Code; LLMs Propose Structure.
19. Solvers Integrate Equations; They Do Not Validate Biology.
20. Reports Explain Results; They Do Not Certify Them.
21. One Source of Truth > Repeated Mapping.
22. Feature Flags Require Rollback Tests.
23. Optional Dependencies Must Declare Degradation.
24. A Green Pipeline Is Not a Green Benchmark.
25. A Rendered Plot Is Not a Correct Model.
26. A PMID Is Evidence Only When It Supports the Claim.
27. An SBML Model Is Ground Truth Only Within Its Scope.
28. Fix Mechanism, Evidence, Parameters, Simulation, and Validation Before Prompt.
29. Preserve User Worktrees; Never Repair History by Deleting Work.
30. Every Scientific Change Must Leave a Reproducible Trail.
